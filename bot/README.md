# Бот «Клетки» в Telegram

Бот открывает приложение, отвечает на команды и принимает добровольную поддержку в Telegram Stars.
Задачи в чате он не решает: решатель работает в приложении на устройстве пользователя.

Работает на Cloudflare Workers (бесплатного тарифа хватает), ничего не хранит.

## Что есть

| Команда | Что делает |
| --- | --- |
| `/start` | Приветствие и кнопка «Открыть Клетку» |
| `/help` | Как вводить задачи |
| `/donate` | Выбор суммы и счёт в звёздах |
| `/paysupport` | Вопросы по оплате (Telegram требует эту команду у ботов с платежами) |
| `/terms` | Условия |
| `/refund <id пользователя> <id платежа>` | Возврат звёзд, только для владельца |

После каждого платежа владельцу приходит сообщение с готовой командой возврата.

## Запуск

1. **Создайте бота.** В [@BotFather](https://t.me/BotFather): `/newbot`, получите токен. Картинку поставьте командой `/setuserpic`, файл `avatar.png` лежит в этой папке.
2. **Проверьте настройки** в `wrangler.toml`:
   - `WEBAPP_URL` — адрес сайта с приложением;
   - `ADMIN_ID` — ваш числовой id (его покажет, например, [@userinfobot](https://t.me/userinfobot));
   - `SUPPORT_CONTACT` — куда писать по оплате, например `@username`;
   - `DONATE_AMOUNTS` — суммы в звёздах.
3. **Выложите бота.** Нужен аккаунт Cloudflare и Node.js:
   ```
   cd bot
   npx wrangler login
   npx wrangler deploy
   ```
   В ответе будет адрес вида `https://kletka-bot.<имя>.workers.dev`.
4. **Задайте секреты.** Токен от BotFather и любую свою случайную строку из латинских букв, цифр, `_` и `-`:
   ```
   npx wrangler secret put BOT_TOKEN
   npx wrangler secret put WEBHOOK_SECRET
   ```
5. **Подключите бота к Telegram.** Откройте в браузере
   `https://kletka-bot.<имя>.workers.dev/setup?key=<ваш WEBHOOK_SECRET>`.
   Должно прийти `"ok"` по всем пунктам: вебхук, команды, описания, кнопка меню.
6. **Включите поддержку на сайте.** В `index.html` в начале скрипта впишите имя бота без `@` и адрес из шага 3:
   ```js
   const BOT_USERNAME = 'имя_бота';
   const BOT_API = 'https://kletka-bot.<имя>.workers.dev';
   ```
   Пока обе строки пустые, блок «Поддержать проект» на сайте скрыт.

Платежи в звёздах отдельно включать не нужно. Накопленные звёзды видны в BotFather в настройках бота, там же условия вывода.

## Проверка

```
cd bot
npm test
```

Тесты идут без сети: запросы к Telegram перехватываются.

## Тексты

Все сообщения бота собраны в начале `worker.js` в объекте `TEXT`. Условия и срок возврата (`/terms`, `/paysupport`) — это ваши обещания пользователям: прочитайте их и поправьте под себя.
